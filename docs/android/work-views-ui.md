# Android：月、周、日工作视图

对应 Issue #29 中曲懿涵负责的 Android 范围（分支 `feature/06-work-views-android`），OpenSpec change 为 `month-week-day-work-views`。接口契约见 [`api-design.md` 3.4 节](../backend/api-design.md)，由 PR #31（`feature/06-work-views-backend`）提供。

## 入口与导航

- 底部“视图”Tab 首次进入显示当前用户的当前月。页面不显示品牌栏和大号标题，只用一行紧凑标题显示当前查看成员（如“陈宁的视图”），右上角提供“任务中心”和“组织关系”入口。进入任务中心后返回，保留原视图模式和周期（`rememberSaveable` 随导航返回栈恢复）。
- 视图页不提供下属选择器。查看下属时从“组织关系 → 成员资料 → 查看视图”进入，路由为 `member-work-views/{memberId}`；按钮仅在成员资料返回 `can_view_work_views=true` 且非本人时显示。页面标题显示“××的视图 · 只读”，左上角返回成员资料，月/周/日切换保持该成员。
- 每次请求都携带 `user_id`（查看本人时省略），权限以后端校验为准；越权时页面显示服务端错误并可重试。

## 月 / 周 / 日

- 月：周期标题打开年月快速选择；左右箭头切换月份，非当前月显示“本月”返回。每个日期最多绘制 3 条任务条，相邻日期同一任务合并为横跨条，超出部分显示服务端返回的准确 `+N项`。已审批、未取消任务只要日期跨度与月份相交就会显示，已完成、未完成或逾期不影响显示。任务条只显示标题，颜色为 `bar_color`；点任务条进详情，点日期格或 `+N项` 进入该日的日视图。
- 周：周期标题打开日历选择窗口，支持切换年份、月份并点选日期，确认后跳到所在周并高亮所选日期（今天另以描边标出）；日期条一行显示周一至周日、不横向滚动；点日期进入该日的日视图。日期条和“全天”任务区固定，只有 00:00–23:00 时间轴纵向滚动。任意所选周显示已审批、未取消且日期跨度与该周相交的负责人任务，已完成、未完成或逾期不影响显示。日期跨度为预计开始日期（未填时为最初创建日期）至截止日期；全天条按与所选周的交集偏移和裁剪，不能一律从周一绘制，也不表示实际工时。非当前周显示“本周”返回。
- 日：周期标题打开日历选择窗口，支持切换年份、月份并点选日期，确认后跳到所选日期；显示所选日期所在周的日期条，点日期切换。任意日期显示已审批、未取消且日期跨度覆盖当天的负责人任务，已完成、未完成或逾期不影响显示；任务条占满所选日宽度，任务开始前和截止日后不显示；真实动态仍按所选日期读取。非今天显示“今天”返回。
- 时区：后端时间戳为 UTC（`Z`，可能带微秒）。客户端的“今天”、周起止、日期分组和卡片时间统一按业务时区 `Asia/Shanghai`（与后端 `TIME_ZONE` 一致）计算，不受设备时区影响。
- 周/日动态卡片按 `occurred_at` 换算到业务时区后归入对应日期与小时，显示时间、任务标题和动态类型，背景为 `tag_color`。同一小时内卡片按时间排序，小时行按该小时最高的单元格扩展，七列行高一致，卡片不越过小时边界。
- 视图底部放置半透明卡通装饰图 `pandora_footer_art`，不遮挡内容点击。

## 任务详情与只读

- 本人视图的任务条/动态进入 `task-center/{id}`。
- 下属视图进入 `work-view-task/{id}`，以 `TaskCenterScreen(forceReadOnly = true)` 打开，不显示编辑、进展、提交、取消等操作；任务详情能否打开仍由后端任务权限决定。
- 视图本身不提供任何任务写操作，也不请求日志接口。

## 测试

- 单元测试 `WorkViewTimeTest`：月任务条合并与 3 条上限、UTC 设备上的业务时区/微秒时间解析、当前周期判断、全部动态类型的中文标签，以及日历选择与业务时区日期转换。
- 契约测试 `WorkViewContractTest`：`src/test/resources/work-views/` 中保存了 PR #31 后端（演示数据，团队长查看员工）的真实响应，验证月视图每日 ≤3 条与溢出数、周 7 个日期与全天条范围、日动态均落在所请求的业务日期且有序、动态字段只有 5 个、成员资料权限字段、越权 403 文案。
- 仪器测试 `WorkViewsUiTest`（11 项）：周任务条起止列定位、周/日日历确认与取消、默认当前月与模式切换、“本月”返回、紧凑标题显示当前成员、月日期格与 `+N项` 进入日视图、周日期条高亮所选日期并进入日视图、下属视图请求带 `user_id` 且任务只读、从任务中心返回保留周视图、成员资料“查看视图”入口的授权显示、只读任务详情无写操作。
- `AccountUiTest` 同步视图页标题与任务中心入口；`BusinessUiTest` 的旧首页用例已改为验证首页请求并显示 `home/` 接口数据。
