# Android：月、周、日工作视图

对应 Issue #29 中曲懿涵负责的 Android 范围（分支 `feature/06-work-views-android`），OpenSpec change 为 `month-week-day-work-views`。接口契约见 [`api-design.md` 3.4 节](../backend/api-design.md)，由 PR #31（`feature/06-work-views-backend`）提供。

## 入口与导航

- 底部“视图”Tab 首次进入显示当前用户的当前月；右上角提供“任务中心”和“组织关系”入口。进入任务中心后返回，保留原视图模式和周期（`rememberSaveable` 随导航返回栈恢复）。
- 视图页不提供下属选择器。查看下属时从“组织关系 → 成员资料 → 查看视图”进入，路由为 `member-work-views/{memberId}`；按钮仅在成员资料返回 `can_view_work_views=true` 且非本人时显示。页面标题显示“××的视图 · 只读”，左上角返回成员资料，月/周/日切换保持该成员。
- 每次请求都携带 `user_id`（查看本人时省略），权限以后端校验为准；越权时页面显示服务端错误并可重试。

## 月 / 周 / 日

- 月：周期标题打开年月快速选择；左右箭头切换月份，非当前月显示“本月”返回。每个日期最多绘制 3 条任务条，相邻日期同一任务合并为横跨条，超出部分显示服务端返回的准确 `+N项`。任务条只显示标题，颜色为 `bar_color`。
- 周：周期标题打开月历日期选择；日期条一行显示周一至周日、不横向滚动；点日期进入该日的日视图。日期条和“全天”未完成任务区固定，只有 00:00–23:00 时间轴纵向滚动。全天条从周一开始，长度到截止日（晚于本周则到周日），不表示工期。非当前周显示“本周”返回。
- 日：显示所选日期所在周的日期条，点日期切换；仅今天由后端返回全天未完成任务。非今天显示“今天”返回。
- 周/日动态卡片按 `occurred_at` 转为设备时区后归入对应日期与小时，显示时间、任务标题和动态类型，背景为 `tag_color`。同一小时内卡片按时间排序，小时行按该小时最高的单元格扩展，七列行高一致，卡片不越过小时边界。
- 视图底部放置半透明卡通装饰图 `pandora_footer_art`，不遮挡内容点击。

## 任务详情与只读

- 本人视图的任务条/动态进入 `task-center/{id}`。
- 下属视图进入 `work-view-task/{id}`，以 `TaskCenterScreen(forceReadOnly = true)` 打开，不显示编辑、进展、提交、取消等操作；任务详情能否打开仍由后端任务权限决定。
- 视图本身不提供任何任务写操作，也不请求日志接口。

## 测试

- 单元测试 `WorkViewTimeTest`：月任务条合并与 3 条上限、时区/微秒时间解析、当前周期判断、全部动态类型的中文标签。
- 仪器测试 `WorkViewsUiTest`：默认当前月与模式切换、“本月”返回、下属视图请求带 `user_id` 且任务只读、从任务中心返回保留周视图、成员资料“查看视图”入口的授权显示、只读任务详情无写操作。
