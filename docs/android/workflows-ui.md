# Android：日志、任务中心与首页

对应 Issue #20、#21、#22 中曲懿涵负责的 Android 范围。界面设计草稿位于 [Pandora Figma](https://www.figma.com/design/GRCCSqaYmz3yRPN1ylLisd/Pandora?node-id=56-352)。

- 日志页提供月份切换、年月选择、个人日期详情、草稿和提交表单，查看对象从授权列表获取；创始人可从“我的”进入标签管理。
- 任务中心提供本人、创建、授权下属和审批列表、筛选、表单、详情、变更历史及相应操作；下属查看入口只读。任务表单和日志表单使用同一标签接口。
- 首页读取四类摘要，跳转对应列表和详情；个人重点支持选择、移除、排序与保存；任务通知只向服务端提交实际可见的未读通知 ID。
- 登录令牌和刷新使用 Android 现有网络设施。列表、表单和操作显示加载或错误信息；不把本地示例当作真实数据。

目前依据仓库 API 设计中的示例实现客户端请求。相关服务尚未交付，字段、错误信息、日期/时区、权限、分页、附件访问以及完整跨角色流程均需要后续与后端联调；这些行为不能由前端隐藏按钮代替服务端校验。测试替身只用于 Android 测试，不会修改或模拟正式后端数据。
