## Why

首页原“个人十大重点工作”把个人安排混在公司任务中。用户需要一个可自行创建、跨多日、按个人日历查看的备忘录模块，让员工能安排自己的事项，同时保持公司任务、工作视图和操作审计边界清楚。

## What Changes

- 首页个人面板改为“每日事项”，只预览当前账号日期范围覆盖今天的事项，最多五条；首页不提供创建入口。
- 增加独立的个人事项月历、创建/编辑表单、颜色选择、日期列表浮窗、事项详情浮窗、确认删除和任务条拖动。
- 每日事项只归属创建账号，不复用公司任务、任务状态、标签关联或操作审计记录。
- 更新需求 02，并新增需求 09。Demo 原型以纯前端本地状态演示，不代表生产后端、持久化或同步已经完成。

## Non-goals

- 不实现公司任务或日志功能，不把每日事项加入公司工作视图或任务看版。
- 不提供按周、月等规则自动重复生成。
- 不增加完成、逾期、优先级、审批、评论、标签、共享或 Web 管理功能。
- 本次 Demo 不实现后端接口、数据库持久化、登录权限或跨设备同步。

## Impact

- 需求文档：`docs/requirements/02-home-four-panels.md`、`docs/requirements/04-month-week-day-work-views.md`、`docs/requirements/09-personal-daily-items.md`。
- OpenSpec：新增 `personal-daily-items` change，替换首页旧的个人任务排序面板定义并定义个人事项行为。
- Demo：`demo/app` 中的 Jetpack Compose 原型首页和个人事项日历界面。
- 生产 Android、Web、后端 API 和数据库实现不属于本次 Demo 代码交付。
