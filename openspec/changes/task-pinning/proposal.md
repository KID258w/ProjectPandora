## Why

用户希望在任务中心快速访问重点任务。当前列表排序和筛选无法让常用任务始终优先显示。

## What Changes

- 为每个 App 账号保存独立的任务置顶关系，并提供查询、置顶和取消置顶接口。
- 任务中心标题下在有置顶任务时显示置顶区；无置顶任务时完全隐藏。
- 置顶区不受普通列表筛选影响，并避免与下方普通列表重复展示。
- 在本人普通任务列表长按任务行显示置顶或取消置顶操作；短按仍打开任务详情。

## Non-goals

- 不提供置顶排序、数量上限、Web 管理入口或下属任务置顶。
- 不改变任务审批、完成、取消、通知或操作审计行为。

## Capabilities

### New Capabilities
- task-pinning: App 用户按账号管理本人任务中心的置顶任务。

## Impact

影响任务中心 Android 页面、任务 API 和数据库；新增账号与任务的置顶关系表，不修改现有任务字段。
