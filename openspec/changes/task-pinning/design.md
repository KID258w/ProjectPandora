## Context

任务中心包含本人创建或承担的已审批任务、审批队列及授权下属只读任务。置顶是个人快速访问偏好，需要跨设备保持，同时不能扩展任务可见权限。

## Decisions

- 使用 `TaskPin(user, task, pinned_at)` 关系表；`(user, task)` 唯一。一个用户可置顶多条任务，按最近置顶时间倒序显示，不设置数量限制。
- 置顶仅允许本人创建或承担的已审批任务。完成或取消不自动清除置顶；不向下属只读列表或审批中心开放置顶。
- 提供 `GET /api/v1/app/tasks/pinned/`、`POST /api/v1/app/tasks/{id}/pin/` 和 `DELETE /api/v1/app/tasks/{id}/pin/`。写操作幂等，服务端逐次校验任务范围。
- 置顶区显示全部当前用户有效的置顶任务，不受普通任务筛选影响；出现在置顶区的任务从本次普通列表结果排除，避免重复。
- 长按普通任务表格行弹出“置顶任务”或“取消置顶”操作；短按继续打开原详情页。
- 置顶是展示偏好，不改变任务业务数据，不触发通知或操作审计。

## Risks / Trade-offs

- 置顶任务即使不匹配当前筛选仍会显示。界面需标明置顶区独立于筛选，并可从该区长按取消置顶。
- 已完成或已取消任务会保留置顶，用户需主动取消；这保证任务进入终态后其置顶偏好不被意外丢弃。
