## Why

员工离职或交接前可能修改大量任务、日志等业务数据。现有 Web 管理审计只记录管理员操作，无法帮助管理员确认员工 App 上发生了哪些变更；如果没有历史值，也难以人工找回被覆盖的数据。

## What Changes

- 新增员工 App 操作审计能力和 Web 独立查询页面，与 Web 管理员操作记录分开。
- 仅记录成功登录和成功的状态变更；任务、日志等业务数据保存变更前后值，供管理员查看并人工处理，不提供一键恢复。
- 审计列表显示操作摘要，单条记录详情显示修改前后字段值；操作者姓名、职位及组织信息按操作发生时快照保存。
- 密码及完整身份证号等敏感值不进入审计快照；不记录只读访问、失败操作、个人重点排序或通知已读。

## Capabilities

### New Capabilities
- `app-operation-audit`: 员工 App 操作记录、业务变更历史值保存及 Web 管理端查询。

## Impact

- 更新 Web 管理需求、后端 API 契约和数据库设计。
- 新增后端员工 App 操作审计实体与仅管理员可访问的只读列表/详情 API。
- Web 可通过专用审计页面查看操作元数据和任务、日志相关变更前后值；不新增常规任务/日志管理能力。
