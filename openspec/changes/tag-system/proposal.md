# Proposal

## Why

任务和日志目前缺少统一的主题标记，工作视图也无法按用户定义的类别保持任务颜色一致。新增全公司共享的 App 标签库，让所有 App 角色在有权编辑的任务和日志中关联标签，并由创始人集中管理标签。

## What Changes

- 在 Android App 为创始人提供标签管理中心；入口仅显示在创始人“我的页面”。所有 App 角色仍可在有权限填写的任务、日志表单中搜索并选择启用标签。
- 新增标签查询、创建、改名和不可逆停用 API；停用保留标签及历史关联，不提供恢复启用。
- 扩展任务创建/编辑/详情、日志保存/详情契约以支持多标签关系，并遵循各自原有的可编辑权限和时间窗口。
- 扩展月、周、日工作视图响应：任务条按当前关联标签中最早添加者着色；无标签时使用中性灰色。视图不返回标签名称供任务条展示。
- 新增标签及任务/日志标签关联的数据表；更新后端 API 与数据库设计文档。

## Capabilities

### New Capabilities

- `tag-system`: 全公司共享标签的管理、任务和日志关联、历史停用行为及工作视图颜色标记。

### Modified Capabilities

无。当前 OpenSpec 尚无已同步的主规格；本次行为由新建的 `tag-system` capability 统一描述。

## Impact

- Android App API：新增标签管理/查询接口；现有任务、日志接口增加标签字段；工作视图接口增加任务条颜色字段。
- 数据库：新增标签表和任务、日志关联表；不改变现有任务、日志主表字段及工作流。
- 文档：依据 `docs/requirements/07-tag-system.md`，同步 `docs/backend/api-design.md` 和 `docs/backend/database-design.md`。
- 不涉及 Web 管理端、管理员权限、任务/日志筛选、任务审批或日志提交规则。
